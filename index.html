최소 구현 요건

본선 진출팀은 아래 다섯 가지를 갖춰야 수상 대상이 됩니다.

  1. 대상과 문제 정의누가, 어떤 상황에서 겪는 문제인지 발표자료에 적습니다.
  2. 작동하는 프로토타입핵심 기능이 실제로 작동하는 모습을 시연합니다.
  3. 핵심 기능에 AI 포함AI가 무엇을 받아 무엇을 판단·생성하는지 설명합니다. 외부 API를 쓰면 API가 맡은 부분과 팀이 만든 부분을 나눠 설명합니다.
  4. 간단한 검증예시 입력 10건 이상의 결과, 또는 사용 시나리오별 동작 확인 결과를 보여 줍니다.
  5. 허용된 데이터만 사용공개 데이터, 직접 만든 모의 데이터, 시뮬레이션 데이터만 씁니다.

시연 안내

  • 시연은 팀이 준비한 노트북으로 합니다. 발표 전에 장비 연결 점검 시간을 드립니다.
  • 노트북에서 돌리기 어려운 모델은 클라우드나 서버에 미리 띄워 두고 시연할 수 있습니다.
  • 네트워크나 장비 문제로 시연이 어려우면 제출한 백업 영상으로 대신할 수 있습니다. 반영 여부는 심사위원이 판단합니다.

개발 기간이 짧습니다. 사용자 한 명, 상황 하나, 핵심 기능 1~2개로 범위를 좁히세요.

    FAQ

    자주 묻는 질문

    AI를 전혀 몰라도 참가할 수 있나요?

    네. 타 학과 학생은 자기 전공 분야의 문제를 가져오는 역할만으로도 충분히 기여할 수 있습니다. 컴퓨터공학·AI 전공 학생과 팀을 이루기를 권합니다. 참가팀이 확정되면 공개 데이터셋과 무료 개발 도구 안내자료를 보내 드립니다.

    신청 내용을 고치거나 취소하고 싶어요.

    신청서는 한 번만 제출할 수 있습니다. 팀원 변경이나 취소는 접수번호와 함께 아래 문의처로 연락해 주세요.

    ChatGPT 같은 생성형 AI로 코드를 짜도 되나요?

    됩니다. 사용한 도구와 범위를 본선 발표자료에 적어 주세요. 질의응답에서 팀원이 코드와 모델의 동작을 설명하지 못하면 감점될 수 있습니다.

    외부 AI API만 붙여서 만들어도 되나요?

    됩니다. API가 맡은 부분과 팀이 설계·구현한 부분을 나눠 설명해 주세요. 그 문제에 그 방법이 맞는지, 팀이 무엇을 만들었는지를 'AI 활용의 적절성' 항목에서 평가합니다.

    GPU나 유료 API 비용을 지원하나요?

    팀별 개발비, 유료 API, 장비 구입비는 지원하지 않습니다. 무료 사용량 안에서 쓸 수 있는 도구와 공개 자원으로 구현해 주세요. 장비를 쓰지 않아도 불리하지 않습니다.

    캡스톤디자인이나 수업 과제를 가져와도 되나요?

    발전시켜 참가할 수 있습니다. 기존 부분과 대회 기간에 새로 만든 부분을 발표자료에 나눠 적어야 하며, 새로 만든 부분을 중심으로 평가합니다. 다른 대회 수상작을 그대로 낼 수는 없습니다.

    어떤 데이터를 쓸 수 있나요?
    • 공개 데이터, 직접 만든 모의 데이터, 시뮬레이션 데이터만 쓸 수 있습니다.
    • 실제 환자·고객·학생의 개인정보나 식별 가능한 건강정보는 쓸 수 없습니다.
    • 공개 데이터는 출처와 이용 조건을 README에 적어 주세요. 승인 절차가 필요한 데이터는 미리 신청하세요.
    • 사람의 얼굴·음성을 쓰면 당사자 동의를 받고, 발표자료와 영상에서는 알아볼 수 없게 처리하세요.
    건강·금융·법률 주제를 골라도 되나요?

    됩니다. 다만 결과물은 교육용 프로토타입이므로 진단·치료 효과나 전문 자문을 대체한다고 표현하지 마세요. 성능은 실제로 시험한 데이터와 조건 안에서만 말해 주세요.

    결과물의 권리는 누구에게 있나요?

    참가팀에 있습니다. 주최 측은 사업 성과 보고와 홍보를 위해 결과물 요약·사진·영상을 쓸 수 있습니다. 출처 없이 남의 저작물·코드를 쓰거나 허위 내용이 확인되면 수상이 취소될 수 있습니다.
