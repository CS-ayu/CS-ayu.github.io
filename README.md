# 2026 안양대학교 AI 경진대회 홈페이지

사이트 주소: **https://cs-ayu.github.io**

학생이 로그인 없이 신청서를 내면, 학과 구글 계정의 구글 시트에 한 줄씩 쌓이는 정적 웹사이트입니다. 서버와 비용이 필요 없습니다. 이 저장소의 파일을 고치고 저장(Commit)하면 1~2분 뒤 사이트에 반영됩니다.

```
index.html            페이지 본문 (대회 안내, FAQ 문구는 여기서 고칩니다)
config.js             날짜·장소·연락처·접수 주소 (대부분의 수정은 여기서)
assets/style.css      디자인
assets/app.js         일정 표시, 신청서 동작
apps-script/Code.gs   신청서를 구글 시트에 저장하는 스크립트 (구글에 붙여 넣는 용도)
```

글꼴은 Pretendard(SIL OFL 1.1)와 Black Han Sans(Google Fonts)를 온라인으로 불러옵니다.

## 파일 고치는 방법 (GitHub 화면에서)

1. 이 저장소에서 고칠 파일(예: `config.js`)을 누릅니다.
2. 오른쪽 위 **연필 아이콘(Edit this file)** 을 누릅니다.
3. 따옴표 안의 글자만 바꿉니다. 쉼표와 따옴표는 지우지 마세요.
4. 오른쪽 위 **Commit changes...** → **Commit changes** 를 누릅니다.
5. 1~2분 뒤 사이트를 새로고침해 확인합니다.

| 바꿀 것 | 고칠 곳 |
| --- | --- |
| 날짜, 본선 장소, 연락처, 주최 명칭, 개인정보 보유 기간, 신청서 접수 주소 | `config.js` |
| 신청 기간 (접수 서버 쪽) | 구글 Apps Script의 `OPEN_AT`, `CLOSE_AT` (config.js와 같게, 새 버전 배포) |
| 안내 문구, FAQ, 심사 기준 설명 | `index.html` (심사 배점은 `assets/app.js`의 `SC`) |

## 신청서 받을 구글 시트 연결하기 (처음 한 번, 10분)

이 단계를 마치기 전에는 사이트의 신청서가 '접수 준비 중'으로 표시됩니다. 학생 개인정보가 쌓이므로 **학과 공용 구글 계정**에서 하는 것을 권합니다.

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 이름 예: `2026 AI 경진대회 신청`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 복사해 붙여 넣습니다. (파일을 열고 오른쪽 위 복사 아이콘)
4. 위쪽 설정에서 `CONTACT`의 전화번호·이메일을 실제 값으로 바꿉니다.
5. 저장한 뒤, 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다. 권한 승인 창이 뜨면 허용합니다. (스프레드시트 접근, 메일 발송 권한)
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 본인이 만든 스크립트라 안전합니다.
   - 시트에 `신청` 탭과 머리글이 생기면 성공입니다.
6. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형: **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
7. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
8. 이 저장소의 `config.js`에서 `applyEndpoint: ""`의 따옴표 안에 그 URL을 붙여 넣고 저장(Commit)합니다.

> Apps Script 코드를 나중에 고치면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 시험 접수 해 보기

1. `config.js`에서 `forceOpen: true`로, Apps Script에서 `TEST_MODE = true`로 바꿉니다. (Apps Script는 새 버전으로 배포)
2. https://cs-ayu.github.io 에서 신청서를 한 번 제출합니다.
3. 접수번호가 뜨고, 시트에 한 줄이 생기고, 확인 메일이 오는지 봅니다.
4. 시험 행을 시트에서 지우고, `forceOpen: false`, `TEST_MODE = false`로 되돌립니다. (Apps Script는 다시 새 버전으로 배포)

## 신청 현황 보기

- 구글 시트 `신청` 탭에 접수 순서대로 쌓입니다. 접수번호는 `AI26-001`부터 매겨집니다.
- 팀원 변경·취소 요청이 오면 시트에서 직접 고치고 `메모` 칸에 기록하세요. 숨겨진 `학번목록` 열은 중복 신청을 막는 데 쓰이니, 팀원을 바꾸면 그 칸의 학번도 같이 고쳐 주세요(`,학번,학번,` 형식).
- 개인 신청자는 `신청유형`이 `개인`인 행입니다. 팀 구성에 쓰세요.

## 개인정보 관리

- 이 저장소는 공개 저장소입니다. 학생 정보는 저장소가 아니라 구글 시트에만 쌓입니다. 저장소에 신청 내용이나 명단을 올리지 마세요.
- 시트는 학과 계정에만 두고, 공유는 운영진으로 한정하세요.
- 보유 기간(기본: 대회 종료 후 1년)이 지나면 시트를 삭제하세요. 기간은 교내 규정을 확인해 `config.js`의 `retention`에서 바꿀 수 있습니다.
- 확인 메일은 시트를 만든 계정의 Gmail에서 나갑니다. 일반 구글 계정은 하루 약 100통까지 보낼 수 있습니다.
